# Saiful Othman BBMA Android V1

Native Android Studio project for the Saiful Othman BBMA V1 prototype.

## Features
- Dashboard
- Chart with Entry / SL / TP
- BUY / SELL signals
- Positions
- Settings
- Portrait phone UI
- Demo/static trading data (not connected to MT5 or a broker)

## Build APK in Android Studio
Open this folder in Android Studio and run **Build > Build APK(s)**.

## Build APK automatically with GitHub Actions
Push this project to GitHub. Open **Actions > Build Android APK**. The generated `app-debug.apk` is uploaded as a workflow artifact.
